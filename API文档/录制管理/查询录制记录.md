# 查询录制记录

## 接口名称
查询录制记录

## 接口描述
查询指定直播流的录制记录

## 请求方法
GET

## 请求路径
```
GET /?bucket=<bucket>&stream&id=<streamId>&record
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| bucket | string | 是 | 空间名称 |
| id | string | 是 | 流ID |
| startTime | string | 否 | 开始时间，ISO8601格式 |
| endTime | string | 否 | 结束时间，ISO8601格式 |
| limit | integer | 否 | 返回数量限制，默认20，最大100 |
| marker | string | 否 | 分页标记 |

## 请求示例
```http
GET /?bucket=test-bucket&stream&id=test-stream-001&record&startTime=2023-01-01T00:00:00Z&endTime=2023-01-01T23:59:59Z HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | array | 录制记录列表 |
| data[].recordId | string | 录制ID |
| data[].streamId | string | 流ID |
| data[].bucket | string | 空间名称 |
| data[].startTime | string | 录制开始时间 |
| data[].endTime | string | 录制结束时间 |
| data[].duration | integer | 录制时长（秒） |
| data[].fileUrl | string | 录制文件URL |
| data[].fileSize | integer | 文件大小（字节） |
| data[].format | string | 文件格式 |
| marker | string | 分页标记，用于获取下一页数据 |

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 404 | 空间或流不存在 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
