# 生成指定时间范围录制文件

## 接口名称
生成指定时间范围录制文件

## 接口描述
为指定直播流生成指定时间范围的录制文件

## 请求方法
POST

## 请求路径
```
POST /?bucket=<bucket>&stream&id=<streamId>&record
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| bucket | string | 是 | 空间名称 |
| id | string | 是 | 流ID |

## 请求Body
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| startTime | string | 是 | 开始时间，ISO8601格式 |
| endTime | string | 是 | 结束时间，ISO8601格式 |
| format | string | 否 | 文件格式，可选值：flv, mp4, hls，默认为mp4 |

## 请求示例
```http
POST /?bucket=test-bucket&stream&id=test-stream-001&record HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json

{
  "startTime": "2023-01-01T10:00:00Z",
  "endTime": "2023-01-01T11:00:00Z",
  "format": "mp4"
}
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | object | 录制任务信息 |
| data.recordId | string | 录制ID |
| data.streamId | string | 流ID |
| data.status | string | 任务状态 |
| data.startTime | string | 录制开始时间 |
| data.endTime | string | 录制结束时间 |

## 响应示例
```json
{
  "requestId": "558f0655-f373-48e6-93fb-7c91020462e0",
  "code": 200,
  "message": "success",
  "data": {
    "recordId": "record-789012",
    "streamId": "test-stream-001",
    "status": "processing",
    "startTime": "2023-01-01T10:00:00Z",
    "endTime": "2023-01-01T11:00:00Z"
  }
}
```

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 404 | 空间或流不存在 |
| 409 | 时间范围无效或无数据 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
