# 描述
保存直播截图

# 接口信息
- **请求方法**: POST
- **请求地址**: `<bucket>`.mls.cn-east-1.qiniumiku.com
- **请求路径**: /<StreamName>

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| snapshot | string | 必须 | 无 | 固定字段，https://developer.qiniu.com/dora/6497/the-queue |

## Header 参数
| 参数名  | 类型 | 必填 | 示例值 | 描述 |
|:--------- |:--------|:-----------|:-----|:---------|:---|
| Host | string | 是 | `<bucket>`.mls.cn-east-1.qiniumiku.com | 请求的服务域名，Host 中的 `<bucket>` 是流所属的空间名称 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

## Body 参数 (application/json)
| 参数名称 | 类型 | 必填 | 描述 |
|:---|:---:|:---:|:---|
| time | integer | 可选 | 截图时间，Unix 时间戳，不指定则为当前时间 |
| fname | string | 可选 | 文件名，不指定系统会随机生成 |
| format | string | 可选 | 文件格式，默认为jpg，可取值为jpg和png |
| pipeline | string | 可选 | 异步模式时，指定数据处理的队列，可以将优先级较高的任务配置到独立的队列中进行执行，参考文档：[流媒体队列](https://developer.qiniu.com/dora/6497/the-queue) |
| notify | string | 可选 | 回调地址，若指定回调地址，则截图动作为异步模式 |
| deleteAfterDays | integer | 可选 | 生命周期，- 0: 默认值，表示截图文件永久保存，单位：天 |



## 请求示例
```http
POST /<StreamName>?snapshot HTTP/1.1
Host: <bucket>.mls.cn-east-1.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json

{
  "time": 1767529570631,
  "fname": "fnema",
  "format": "jpg",
  "pipeline": "",
  "notify": "",
  "deleteAfterDays": 40
}
```
