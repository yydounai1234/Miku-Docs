# 录制管理

## 概述
录制管理模块提供对直播流录制功能的管理，包括查询录制记录和生成指定时间范围的录制文件等操作。

## 功能列表
- [查询录制记录](查询录制记录.md) - GET
- [生成指定时间范围录制文件](生成指定时间范围录制文件.md) - POST

## 录制文件格式
支持以下录制文件格式：
- FLV格式
- MP4格式
- HLS格式（M3U8 + TS片段）

## 录制存储
录制文件默认存储在与直播空间关联的对象存储空间中，可以通过配置指定存储位置。

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
