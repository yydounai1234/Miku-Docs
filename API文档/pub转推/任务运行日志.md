# 描述
查询指定 pub 转推任务的运行日志。

# 接口信息
- **请求方法**: `GET`
- **请求地址**: `pub-manager.mikudns.com`
- **请求路径**: `/tasks/<taskID>/runinfo`

# 请求参数
## Header 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| Host | string | 是 | `pub-manager.mikudns.com` | 服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken |

## Path 参数
| 参数名称 | 类型 | 必填 | 描述 |
|:---|:---:|:---:|:---|
| taskID | string | 是 | 任务 ID |

# 请求示例
```http
GET /tasks/<taskID>/runinfo HTTP/1.1
Host: pub-manager.mikudns.com
Authorization: <QiniuToken>
```
