

# 描述
列举 pub 转推任务列表。

# 接口信息
- **请求方法**: `GET`
- **请求地址**: `pub-manager.mikudns.com`
- **请求路径**: `/tasks`

# 请求参数
## Header 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| Host | string | 是 | `pub-manager.mikudns.com` | 服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

## Query 参数
| 参数名称 | 类型 | 必填 | 描述 |
|:---|:---:|:---:|:---|
| marker | string | 否 | 翻页游标 |
| limit | integer | 否 | 返回数量上限，最大 1000 |
| name | string | 否 | 任务名称/描述模糊匹配 |

# 请求示例
```http
GET /tasks?marker=123&limit=100&name=demo HTTP/1.1
Host: pub-manager.mikudns.com
Authorization: <QiniuToken>
```

## 返回参数
| 参数名称 | 类型 | 说明 |
|:---|:---:|:---|
| marker | string | 下一页游标 |
| isEnd | boolean | 是否已到末尾 |
| list | array\<object\> | 任务列表 |
| ├─ taskID | string | 任务 ID |
| ├─ uid | integer | 用户 ID |
| ├─ name | string | 任务名称 |
| ├─ desc | string | 任务描述 |
| ├─ runType | string | 任务类型，`normal`/`seek` |
| ├─ sourceUrls | array\<object\> | 源地址列表 |
| ├─ forwardUrls | array\<object\> | 转推地址列表 |
| ├─ filter | object | 过滤条件 |
| ├─ status | string | 任务状态，`pending`/`running`/`stopped`/`failed`/`finished` |
| ├─ deliverStartTime | integer | 定时开始时间，ms |
| ├─ deliverStopTime | integer | 定时结束时间，ms |
| ├─ startTime | integer | 任务开始时间，ms |
| ├─ stopTime | integer | 任务停止时间，ms |
| ├─ createTime | integer | 创建时间，ms |
| ├─ loopTimes | integer | 循环次数 |
| ├─ retryTime | integer | 断流重试时间，秒 |
| ├─ retry | integer | 剩余重试次数 |
| ├─ preload | object | 预加载配置 |
| ├─ preloadStatus | string | 预加载状态 |
| └─ statusCallback | object | 回调配置 |
