# 描述
查询 pub 转推任务的历史运行记录。

# 接口信息
- **请求方法**: `GET`
- **请求地址**: `pub-manager.mikudns.com`
- **请求路径**: `/history`

# 请求参数
## Header 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| Host | string | 是 | `pub-manager.mikudns.com` | 服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

## Query 参数
| 参数名称 | 类型 | 必填 | 描述 |
|:---|:---:|:---:|:---|
| marker | string | 否 | 翻页游标 |
| limit | integer | 否 | 返回数量上限，最大 1000 |
| name | string | 否 | 任务名称前缀匹配 |
| start | integer | 否 | 开始时间，毫秒 |
| end | integer | 否 | 结束时间，毫秒 |

# 请求示例
```http
GET /history?marker=xxx&limit=100&name=task&start=1667459219157&end=1667459220156 HTTP/1.1
Host: pub-manager.mikudns.com
Authorization: <QiniuToken>
```

# 返回响应

## 响应状态码
- **请查阅**: [这里](/mikustream/api/12894/mikustream-live-error-code)


## 响应示例
```json
{
  "marker": "",
  "isEnd": true,
  "histories": [
    {
      "name": "name",
      "startTime": 1667459219157,
      "stopTime": 1667459220156,
      "message": ""
    }
  ]
}
```

## 返回参数
| 参数名称 | 类型 | 说明 |
|:---|:---:|:---|
| marker | string | 翻页游标 |
| isEnd | boolean | 是否已到末尾 |
| histories | array\<object\> | 历史记录列表 |
| ├─ name | string | 任务名称 |
| ├─ startTime | integer | 开始时间，毫秒 |
| ├─ stopTime | integer | 结束时间，毫秒 |
| └─ message | string | 任务消息/描述 |
