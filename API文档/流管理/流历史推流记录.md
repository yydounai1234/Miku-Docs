# 描述
查询指定时间范围内的流历史推流记录，可按空间、推流域名、流名分页过滤。

# 接口信息
- **请求方法**: GET
- **请求地址**: mls.cn-east-1.qiniumiku.com
- **请求路径**: /

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| historyactivity | string | 必须 | 无 | 固定字段 |
| start | string | 必须 | 1707122646123 | 查询开始时间，支持毫秒时间戳、秒级时间戳、日期时间或日期格式 |
| end | string | 必须 | 1707126246123 | 查询结束时间，支持毫秒时间戳、秒级时间戳、日期时间或日期格式 |
| domain | string | 可选 | publish.example.com | 推流域名，`domain` 和 `bucket` 二选一 |
| bucket | string | 可选 | sdk-live | 空间名称，`domain` 和 `bucket` 二选一 |
| streamName | string | 可选 | test-stream | 流名 |
| limit | integer | 可选 | 10 | 每页返回条数 |
| offset | integer | 可选 | 0 | 分页偏移量 |
| orderBy | string | 可选 | publish_time_desc | 排序方式，可选值：`publish_time_asc`、`publish_time_desc`、`stream_name_asc`、`stream_name_desc` |

> `start` / `end` 支持的格式包括：毫秒时间戳（如 `1707122646123`）、秒级时间戳（如 `1588776655`）、日期时间（如 `20060102150405`、`2006-01-02-15-04-05`、`2006-01-02T15:04:05`）以及日期（如 `20060102`、`2006-01-02`）。

## Header 参数
| 参数名 | 位置 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---|:---:|:---:|:---|:---|
| Host | header | string | 是 | mls.cn-east-1.qiniumiku.com | 请求的服务域名 |
| Authorization | header | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

# 请求示例
```http
GET /?historyactivity&start=1707122646123&end=1707126246123&bucket=sdk-live HTTP/1.1
Host: mls.cn-east-1.qiniumiku.com
Authorization: <QiniuToken>
```
