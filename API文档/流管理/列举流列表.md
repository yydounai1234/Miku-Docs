# 描述
列举指定直播空间中的活跃流信息，如果传递了start & end, 则查询在 start 和 end 之间有推流数据的流信息，
没有传 start & end， 则查询所有推流数据的流信息

# 接口信息
- **请求方法**: GET
- **请求路径**: /
- **请求参数**:
  - **streamlist** (string) - 固定 prefix，必需
  - **prefix** (string) - 流名前缀，可选  
  - **offset** (string) - 游标，表示从该位置开始返回 默认为 0，可选  
    示例值:`1`
  - **limit** (string) - 返回个数 limit 默认为 10, 若 <=0 默认最大返回 500 条数据，可选  
    示例值:`10`
  - **domain** (string) - 推流域名，可选  
    bucketId domain 必须二传一  
    示例值:`qiniu.com`
  - **start** (integer) - 最近一次推流开始时间，可选
  - **end** (integer) - 最近一次推流结束时间，可选
  - **bucketId** (string) - bucketId，可选  
    bucketId domain 必须二传一
  - **isForbid** (boolean) - 是否只查询被封禁的流，可选

# 请求参数
## Header 参数
|   参数名	|   位置	 |   类型	   |必填	 |示例值	|描述|
|:--------- |:--------|:-----------|:-----|:---------|:---|
| Host | string | 是 | `<bucket>`.mls.cn-east-1.qiniumiku.com | 请求的服务域名，Host 中的 `<bucket>` 是流所属的空间名称 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

# 请求示例
```http
GET /?streamlist&prefix&offset=1&limit=10&liveonly=true&domain=qiniu.com&start&end&bucketId&isForbid HTTP/1.1
Host: mls.cn-east-1.qiniumiku.com
Authorization: <QiniuToken>
```

# 返回响应
## 响应状态码
- **请查阅**: [这里](/mikustream/api/12894/mikustream-live-error-code)

## 响应示例
```json
{
    "items": [
        {
            "key": "stream1",
            "bucket": "cdntest",
            "creationDate": 1705376688,
            "status": "online",
            "lastStartAt": 1701708771
        }
    ],
    "total": 29
}
```
## 响应参数
| 参数名称 | 类型 | 说明 | 是否必需 |
|:---------|:------|:------|:----------|
| items | []object | 流列表数据 | 必需 |
| &nbsp;&nbsp;&nbsp;&nbsp;├─ key | string | 流名称 | 必需 |
| &nbsp;&nbsp;&nbsp;&nbsp;├─ forbidden | boolean | 是否禁播流 | 必需 |
| &nbsp;&nbsp;&nbsp;&nbsp;├─ creationDate | string | 创建时间（时间类型） | 必需 |
| &nbsp;&nbsp;&nbsp;&nbsp;├─ status | string | 状态（online / offline） | 必需 |
| &nbsp;&nbsp;&nbsp;&nbsp;├─ lastStartAt | integer | 最近一次推流时间（Unix 毫秒时间戳） | 必需 |
| &nbsp;&nbsp;&nbsp;&nbsp;└─ publishUrl | string | 推流 URL | 必需 |
| total | integer | 总数 | 必需 |
| totalPage | string | 总页数 | 必需 |
| pageIndex | string | 分页码 | 必需 |
| pageSize | string | 分页大小 | 必需 |
