# 描述
列举指定直播空间中的活跃流信息，如果传递了start & end, 则查询在 start 和 end 之间有推流数据的流信息，
没有传 start & end， 则查询所有推流数据的流信息

# 接口信息
- **请求方法**: GET
- **请求地址**: mls.cn-east-1.qiniumiku.com
- **请求路径**: /

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| streamlist | string | 必须 | 无 | 固定字段 |
| prefix | string | 可选 | - | 流名前缀 |
| offset | string | 可选 | 1 | 游标，表示从该位置开始返回 默认为 0 |
| limit | string | 可选 | 10 | 返回个数 limit 默认为 10, 若 <=0 默认最大返回 500 条数据 |
| domain | string | 可选 | qiniu.com | 推流域名, bucketId domain 必须二传一 |
| start | integer | 可选 | 1705376688 | 最近一次推流开始时间   |
| end | integer | 可选 | 1705376688 | 最近一次推流结束时间   |
| bucketId | string | 可选 | - | bucketId, bucketId domain 必须二传一 |
| isForbid | boolean | 可选 | - | 是否只查询被封禁的流 |

## Header 参数
|   参数名	|   位置	 |   类型	   |必填	 |示例值	|描述|
|:--------- |:--------|:-----------|:-----|:---------|:---|
| Host | string | 是 | mls.cn-east-1.qiniumiku.com | 请求的服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

# 请求示例
```http
GET /?streamlist&prefix&offset=1&limit=10&liveonly=true&domain=qiniu.com&start&end&bucketId&isForbid HTTP/1.1
Host: mls.cn-east-1.qiniumiku.com
Authorization: <QiniuToken>
```
