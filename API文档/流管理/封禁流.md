# 描述
封禁指定的直播流，禁止其推流和播放

# 接口信息
- **请求方法**: POST
- **请求地址**: `<bucket>`.mls.cn-east-1.qiniumiku.com
- **请求路径**: /<key>

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| forbid | string | 必须 | 无 | 固定封禁字段 |
| bucket | string | 必须 | - | 具体的 bucket 名称 |
| streamKey | string | 必须 | - | 具体的流名称 |

## Header 参数
|   参数名	|   位置	 |   类型	   |必填	 |示例值	|描述|
|:--------- |:--------|:-----------|:-----|:---------|:---|
| Host | string | 是 | `<bucket>`.mls.cn-east-1.qiniumiku.com | 请求的服务域名，Host 中的 `<bucket>` 是流所属的空间名称 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

## Body 参数 (application/json)
示例：
```json
{
    "forbiddenTill": 0
}
```
## 参数
| 参数名称 | 类型 | 说明 | 是否必需 |
|:------|:------|:------|:----------|
| forbiddenTill | integer  | 禁播结束时间，Unix 秒级时间戳，特殊值含义：默认 0 永久禁播,-1解除封禁  | 可选 |

# 请求示例
```http
POST /<key>?forbid&bucket=test-bucket&streamKey=test-stream HTTP/1.1
Host: <bucket>.mls.cn-east-1.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
Content-Length: 26

{
    "forbiddenTill": 0
}
```
