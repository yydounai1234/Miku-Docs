# 错误返回

通用错误返回格式
```
{
    "code": <string>,     // 错误码
    "message": <string>,  // 详细错误信息
    "document": <string>, // 错误信息对应的文档 URL, omitempty
    "resource": <string>, // 错误涉及的空间或对象
    "requestID": <string> // 唯一请求 ID
}
```
