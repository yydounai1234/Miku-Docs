# 新增实时流转码模板

## 接口名称
新增实时流转码模板

## 接口描述
创建一个新的实时流转码模板

## 请求方法
POST

## 请求路径
```
POST /?template=transcode
```

## 请求Body
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| name | string | 是 | 模板名称 |
| description | string | 否 | 模板描述 |
| video | object | 是 | 视频参数 |
| video.codec | string | 是 | 视频编码格式，如h264, h265 |
| video.width | integer | 是 | 视频宽度 |
| video.height | integer | 是 | 视频高度 |
| video.bitrate | integer | 是 | 视频码率（bps） |
| video.framerate | integer | 否 | 视频帧率 |
| audio | object | 否 | 音频参数 |
| audio.codec | string | 否 | 音频编码格式，如aac |
| audio.bitrate | integer | 否 | 音频码率（bps） |
| audio.samplerate | integer | 否 | 音频采样率 |
| format | string | 否 | 封装格式，如flv, hls, rtmp |

## 请求示例
```http
POST /?template=transcode HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json

{
  "name": "720p-template",
  "description": "720p转码模板",
  "video": {
    "codec": "h264",
    "width": 1280,
    "height": 720,
    "bitrate": 1500000,
    "framerate": 30
  },
  "audio": {
    "codec": "aac",
    "bitrate": 128000,
    "samplerate": 44100
  },
  "format": "hls"
}
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | object | 模板信息 |
| data.templateId | string | 模板ID |
| data.name | string | 模板名称 |
| data.createTime | string | 创建时间 |

## 响应示例
```json
{
  "requestId": "558f0655-f373-48e6-93fb-7c91020462e0",
  "code": 200,
  "message": "success",
  "data": {
    "templateId": "tpl-123456",
    "name": "720p-template",
    "createTime": "2023-01-01T00:00:00Z"
  }
}
```

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 409 | 模板名称已存在 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
