# 获取实时流转码模板具体信息

## 接口名称
获取实时流转码模板具体信息

## 接口描述
获取指定ID的实时流转码模板详细信息

## 请求方法
GET

## 请求路径
```
GET /?template=transcode&id=<templateId>
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| id | string | 是 | 模板ID |

## 请求示例
```http
GET /?template=transcode&id=tpl-123456 HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | object | 模板详细信息 |
| data.templateId | string | 模板ID |
| data.name | string | 模板名称 |
| data.description | string | 模板描述 |
| data.video | object | 视频参数 |
| data.video.codec | string | 视频编码格式 |
| data.video.width | integer | 视频宽度 |
| data.video.height | integer | 视频高度 |
| data.video.bitrate | integer | 视频码率（bps） |
| data.video.framerate | integer | 视频帧率 |
| data.audio | object | 音频参数 |
| data.audio.codec | string | 音频编码格式 |
| data.audio.bitrate | integer | 音频码率（bps） |
| data.audio.samplerate | integer | 音频采样率 |
| data.format | string | 封装格式 |
| data.createTime | string | 创建时间 |
| data.updateTime | string | 更新时间 |

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 404 | 模板不存在 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
