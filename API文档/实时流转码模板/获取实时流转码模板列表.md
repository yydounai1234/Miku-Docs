# 获取实时流转码模板列表

## 接口名称
获取实时流转码模板列表

## 接口描述
获取所有实时流转码模板的列表

## 请求方法
GET

## 请求路径
```
GET /?template=transcode
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| limit | integer | 否 | 返回数量限制，默认20，最大100 |
| marker | string | 否 | 分页标记 |

## 请求示例
```http
GET /?template=transcode&limit=10 HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | array | 模板列表 |
| data[].templateId | string | 模板ID |
| data[].name | string | 模板名称 |
| data[].description | string | 模板描述 |
| data[].createTime | string | 创建时间 |
| data[].updateTime | string | 更新时间 |
| marker | string | 分页标记，用于获取下一页数据 |

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
