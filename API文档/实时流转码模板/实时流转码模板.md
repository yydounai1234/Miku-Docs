# 实时流转码模板

## 概述
实时流转码模板模块提供对直播流转码模板的管理功能，包括模板的创建、更新、删除、列表获取和详细信息查询等操作。

## 功能列表
- [新增实时流转码模板](新增实时流转码模板.md) - POST
- [更新实时流转码模板](更新实时流转码模板.md) - PUT
- [删除实时流转码模板](删除实时流转码模板.md) - DELETE
- [获取实时流转码模板列表](获取实时流转码模板列表.md) - GET
- [获取实时流转码模板具体信息](获取实时流转码模板具体信息.md) - GET

## 转码模板说明
转码模板定义了直播流转码的参数配置，包括：
- 视频编码参数（分辨率、码率、帧率等）
- 音频编码参数（采样率、码率等）
- 封装格式
- 转码策略

## 应用场景
- 适应不同网络环境的播放需求
- 生成多种分辨率的流以适配不同设备
- 降低带宽成本
- 提高播放体验

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
