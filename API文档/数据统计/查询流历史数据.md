# 描述
查询流历史数据

# 接口信息
- **请求方法**: `GET`
- **请求地址**: mls.cn-east-1.qiniumiku.com
- **请求路径**: `/`

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| streamStats | string | 必须 | 无 | 固定字段 |
| start | integer | 必须 | 1635162331 | 查询的起始时间 |
| end | integer | 必须 | 1635164952 | 查询的结束时间 |
| domain | string | 必须 | example.push.com | domain、bucket二选一 |
| bucket | string | 必须 | bucket-test | domain、bucket二选一 |
| stream | string | 必须 | - | stream名称 |
| g | string | 可选 | 1min/5min/hour/day | 粒度 默认1min 可选1min/5min/hour/day |

## Header 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| Host | string | 是 | mls.cn-east-1.qiniumiku.com | 请求的服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |


# 请求示例
```http
GET /?streamStats&start=1635162331&end=1635164952&domain=example.push.com&bucket=bucket-test&stream&g=1min/5min/hour/day HTTP/1.1
Host: mls.cn-east-1.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json

```
