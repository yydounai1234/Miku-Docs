# 描述
查询离线日志

# 接口信息
- **请求方法**: `GET`
- **请求地址**: miku-statd.qiniuapi.com
- **请求路径**: `/statd/v1/livelog/split`

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| domain | string | 必须 | pili-live-hdl.apis.com | 需要查询的域名 |
| start | integer | 必须 | 1697792405 | 查询的起始时间 |
| end | integer | 必须 | 1698019104 | 查询的结束时间 |

## Header 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| Host | string | 是 | mls.cn-east-1.qiniumiku.com | 请求的服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |


# 请求示例
```http
GET /statd/v1/livelog?domain=pili-live-hdl.apis.com&start=1697792405&end=1698019104 HTTP/1.1
Host: miku-statd.qiniuapi.com
Authorization: <QiniuToken>
Content-Type: application/json

```

## 响应参数
| 参数名称 | 类型 | 说明 | 是否必需 |
|:---------|:------|:------|:----------|
| totalCount | integer | 离线日志数量 | 必需 |
| requestID | string | 请求 id | 必需 |
| logInfoList | array [object] | 离线日志列表，数组对象字段可见 [logInfo](#logInfo) | 必需 |

### <span id="logInfo">logInfo</span>
| 参数名称 | 类型 | 说明 | 是否必需 |
|:---------|:------|:------|:----------|
| baseFileName | string | 日志文件名称 | 必需 |
| time | string | 时间 | 必需 |
| files | array [object] | 文件列表，具体文件对象可见 [file](#file) | 必需 |

### <span id="file">file</span>
| 参数名称 | 类型 | 说明 | 是否必需 |
|:---------|:------|:------|:----------|
| url | string | 文件下载地址 | 必需 |
| fileName | string | 日志文件名称 | 必需 |
| fsize | string | 文件大小，字节 | 必需 |
