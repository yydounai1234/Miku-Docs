# 实用工具

## 概述
实用工具模块提供一些常用的辅助功能，帮助用户更好地使用直播服务。

## 功能列表
### Apikey管理
- [创建 apikey](Apikey/创建apikey.md) - POST
- [删除 apikey](Apikey/删除apikey.md) - DELETE
- [apikey 列表](Apikey/apikey列表.md) - GET
- [重命名 apikey](Apikey/重命名apikey.md) - PUT

## Apikey说明
Apikey是用于身份验证和授权的密钥，用户可以通过Apikey管理功能创建、删除、查看和重命名Apikey。

## 使用场景
- 自动化脚本调用API
- 第三方系统集成
- 服务器端应用访问

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
