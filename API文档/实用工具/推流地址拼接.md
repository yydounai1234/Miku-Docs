# 描述
推流地址拼接

> 通用域名使用rtmp格式的推流地址

# 接口信息
- **请求方法**: `POST`
- **请求地址**: `<bucket>`.mls.cn-east-1.qiniumiku.com
- **请求路径**: `/<streamKey>`

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| publishUrl | string | 必须 | - | 固定字段 |

## Header 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| Host | string | 是 | mls.cn-east-1.qiniumiku.com | 请求的服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |


## Body 参数 (application/json)
示例：
```json
{
    "expireTime": 0,
    "domain": "rtmp.test.qbox.net"
}
```
## 参数
| 参数名称 | 类型 | 是否必需 | 说明 |
|:---|:---:|:---:|:---|
| expireTime | integer | 可选 | 过期秒数, 默认 300(5分钟) >= 0 |
| domain | string | 必需 | 推流域名 >= 10 字符 <= 20 字符 |


# 请求示例
```http
GET /<streamKey>?publishUrl HTTP/1.1
Host: test.mls.cn-east-1.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json

{
    "expireTime": 0,
    "domain": "rtmp.test.qbox.net"
}
```

# 返回响应
## 响应状态码
- **请查阅**: [这里](/mikustream/api/12894/mikustream-live-error-code)

## 响应示例
```json
{
    "expireAt": 1729502326,
    "isCustomizedSecurity": false,
    "securityType": "tsExpireMD5",
    "url": "https://concrete-brush.org/dsa/das?t=21321213&sign=qwdsdqwdqw"
}
```
## 响应参数
| 参数名称 | 类型 | 说明 | 是否必需 |
|:---------|:------|:------|:----------|
| expireAt | integer | 过期的unix时间戳 秒级别 默认为 0 | 必需 |
| isCustomizedSecurity | boolean | 是否是自定义鉴权 默认为 0,几个特殊客户会为 true | 必需 |
| securityType | string | 鉴权类型 无鉴权返回 none | 必需 |
| url | string | 推流链接 | 必需 |
