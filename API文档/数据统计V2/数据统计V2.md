## 统计数据维度
- 时间维度：分钟、小时、天、月
- 地域维度：国家、省份、城市
- 运营商维度：电信、联通、移动等
- 设备维度：iOS、Android、Web等

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
