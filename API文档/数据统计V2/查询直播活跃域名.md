# 查询直播活跃域名

## 接口名称
查询直播活跃域名

## 接口描述
查询指定时间范围内活跃的直播域名

## 请求方法
GET

## 请求路径
```
GET /?statistic=domain&active
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| startTime | string | 是 | 开始时间，ISO8601格式 |
| endTime | string | 是 | 结束时间，ISO8601格式 |
| type | string | 否 | 域名类型，可选值：publish（推流）, play（播放） |
| limit | integer | 否 | 返回数量限制，默认20，最大100 |

## 请求示例
```http
GET /?statistic=domain&active&startTime=2023-01-01T00:00:00Z&endTime=2023-01-01T23:59:59Z&type=play&limit=10 HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | array | 活跃域名列表 |
| data[].domain | string | 域名 |
| data[].type | string | 域名类型 |
| data[].bucketCount | integer | 使用该域名的空间数量 |
| data[].streamCount | integer | 通过该域名的流数量 |
| data[].traffic | integer | 该域名的总流量（字节） |

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../../公共API规范/请求鉴权.md)文档。
