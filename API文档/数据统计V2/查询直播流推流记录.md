# 查询直播流推流记录

## 接口名称
查询直播流推流记录

## 接口描述
查询指定时间范围内直播流的推流记录

## 请求方法
GET

## 请求路径
```
GET /?statistic=stream&publish&record
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| startTime | string | 是 | 开始时间，ISO8601格式 |
| endTime | string | 是 | 结束时间，ISO8601格式 |
| bucket | string | 否 | 空间名称，不指定则查询所有空间 |
| streamId | string | 否 | 流ID，不指定则查询所有流 |
| limit | integer | 否 | 返回数量限制，默认20，最大100 |
| marker | string | 否 | 分页标记 |

## 请求示例
```http
GET /?statistic=stream&publish&record&startTime=2023-01-01T00:00:00Z&endTime=2023-01-01T23:59:59Z&bucket=test-bucket&limit=10 HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | array | 推流记录列表 |
| data[].streamId | string | 流ID |
| data[].bucket | string | 空间名称 |
| data[].startTime | string | 推流开始时间 |
| data[].endTime | string | 推流结束时间 |
| data[].duration | integer | 推流时长（秒） |
| data[].clientIp | string | 推流客户端IP |
| data[].userAgent | string | 推流客户端User-Agent |
| marker | string | 分页标记，用于获取下一页数据 |

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../../公共API规范/请求鉴权.md)文档。
