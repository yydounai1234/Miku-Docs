# 查询在线流信息

## 接口名称
查询在线流信息

## 接口描述
查询当前在线直播流的实时信息

## 请求方法
GET

## 请求路径
```
GET /?statistic=stream&online
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| bucket | string | 否 | 空间名称，不指定则查询所有空间 |
| domain | string | 否 | 域名，不指定则查询所有域名 |
| limit | integer | 否 | 返回数量限制，默认20，最大100 |
| marker | string | 否 | 分页标记 |

## 请求示例
```http
GET /?statistic=stream&online&bucket=test-bucket&limit=10 HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | array | 在线流列表 |
| data[].streamId | string | 流ID |
| data[].bucket | string | 空间名称 |
| data[].domain | string | 域名 |
| data[].viewers | integer | 当前观看人数 |
| data[].bandwidth | integer | 当前带宽使用量（bps） |
| data[].startTime | string | 推流开始时间 |
| data[].resolution | string | 分辨率 |
| data[].framerate | integer | 帧率 |
| marker | string | 分页标记，用于获取下一页数据 |

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../../公共API规范/请求鉴权.md)文档。
