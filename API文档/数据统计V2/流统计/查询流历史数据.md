# 查询流历史数据

## 接口名称
查询流历史数据

## 接口描述
查询指定流的历史数据统计信息

## 请求方法
GET

## 请求路径
```
GET /?statistic=stream&history
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| startTime | string | 是 | 开始时间，ISO8601格式 |
| endTime | string | 是 | 结束时间，ISO8601格式 |
| bucket | string | 是 | 空间名称 |
| streamId | string | 是 | 流ID |
| interval | string | 否 | 时间间隔，可选值：minute, hour, day, month，默认为hour |

## 请求示例
```http
GET /?statistic=stream&history&startTime=2023-01-01T00:00:00Z&endTime=2023-01-01T23:59:59Z&bucket=test-bucket&streamId=test-stream-001&interval=hour HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | object | 流历史数据 |
| data.streamId | string | 流ID |
| data.bucket | string | 空间名称 |
| data.metrics | array | 指标数据列表 |
| data.metrics[].timestamp | string | 时间戳 |
| data.metrics[].viewers | integer | 观看人数 |
| data.metrics[].bandwidth | integer | 带宽使用量（bps） |
| data.metrics[].traffic | integer | 流量（字节） |
| data.metrics[].duration | integer | 观看时长（秒） |

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 404 | 流不存在 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../../公共API规范/请求鉴权.md)文档。
