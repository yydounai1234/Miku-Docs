# 描述
创建合流

# 接口信息
- **请求方法**: `POST`
- **请求地址**: `<bucket>`.mls.cn-east-1.qiniumiku.com
- **请求路径**: `/`

# 请求参数
## Query 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| createmerge | string | 必须 | 无 | 固定字段 |

## Header 参数
| 参数名称 | 类型 | 必填 | 示例值 | 描述 |
|:---|:---:|:---:|:---|:---|
| Host | string | 是 | `<bucket>`.mls.cn-east-1.qiniumiku.com | 请求的服务域名 |
| Authorization | string | 是 | `<QiniuToken>` | 管理凭证 QiniuToken，[生成规则](/mikustream/api/12893/mikustream-live-http-requests-authentication) |

## Body 参数 (application/json)
示例：
```json
{
  "id":"123456",
  "duration":100000,
  "inputs": [{
          "chnl": 0,
          "source": "rtmp://pili-live-rtmp.xrtest.cloudvdn.com/xrtest/input1",
          "chromakey": "0x004D00:0.1:0.0"
      },
      {
          "chnl": 1,
          "source": "rtmp://pili-live-rtmp.xrtest.cloudvdn.com/xrtest/input2"
      }
  ],
  "config": {
      "layout": "203",
      "width": 1280,
      "height": 720,
      "fps": 25,
      "kbps": 2000
  },
  "outputs": [{
      "type": "rtmp",
      "url": "rtmp://pili-publish.qnsdk.com/sdk-live/testmediamerge123"
  }]
}
```
## 参数
| 参数名称 | 类型 | 是否必需 | 说明 |
|:---|:---:|:---:|:---|
| id | string | 必须 | 合流id， 为此次合流标识 |
| duration | integer | 必须 | 合流运行时长 |
| inputs | array [object]  | 必须 | 合流输入，数组对象字段可见 [inputs] |
| config | object  | 必须 | 合流后输出图像配置，对象字段可见 [config] |
| output | array [object]  | 必须 | 合流输出，对象字段可见 [output] |

### <span id="inputs">inputs</span>
| 字段 | 类型 | 必填 | 取值范围 | 说明 |
|:---|:---:|:---:|:---:|:---|
| chnl | integer | 必须 | input图像所处位置，对应layout布局中的通道位置 |
| source | string | 必须 | - | input源地址 |
| chromakey | string | 否 | - | 去绿幕参数，数字人时使用 |
| position | object | 否 | - | 特别指定input图像所处位置及宽高，对象字段可见 [position] |

### <span id="position">position</span>
| 字段 | 类型 | 必填 | 取值范围 | 说明 |
|:---|:---:|:---:|:---:|:---|
| x | integer | 必须 | 起始x坐标 |
| y | integer | 必须 | 起始y坐标 |
| w | integer | 必须 | 起始w坐标 |
| h | integer | 必须 | 起始h坐标 |
| z | integer | 必须 | z-order，[1:65534] |

### <span id="config">config</span>
| 字段 | 类型 | 必填 | 取值范围 | 说明 |
|:---|:---:|:---:|:---:|:---|
| layout | string | 必须 | 选择内置布局，例："auto","100","200" |
| width | integer | 必须 | - | 画布宽 |
| height | integer | 必须 | - | 画布高 |
| fps | integer | 必须 | - | 合流输出帧率 |
| kbps | integer | 必须 | - | 合流输出码率 |

### <span id="outputs">outputs</span>
| 字段 | 类型 | 必填 | 取值范围 | 说明 |
|:---|:---:|:---:|:---:|:---|
| type | string | 必须 | 合流输出格式 |
| url | string | 必须 | 合流输出地址 |
