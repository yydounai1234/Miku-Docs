# 创建合流

## 接口名称
创建合流

## 接口描述
创建多路直播流的混合流

## 请求方法
POST

## 请求路径
```
POST /?mix=stream
```

## 请求Body
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| mixId | string | 是 | 合流ID |
| bucket | string | 是 | 空间名称 |
| layout | object | 是 | 合流布局配置 |
| layout.mode | string | 是 | 布局模式，如pip(画中画), grid(平铺) |
| layout.custom | array | 否 | 自定义布局配置 |
| layout.custom[].streamId | string | 是 | 流ID |
| layout.custom[].x | integer | 是 | X坐标 |
| layout.custom[].y | integer | 是 | Y坐标 |
| layout.custom[].width | integer | 是 | 宽度 |
| layout.custom[].height | integer | 是 | 高度 |
| layout.custom[].zOrder | integer | 否 | 层级顺序 |
| streams | array | 是 | 参与合流的流列表 |
| streams[].streamId | string | 是 | 流ID |
| streams[].bucket | string | 是 | 空间名称 |
| output | object | 是 | 输出配置 |
| output.streamId | string | 是 | 输出流ID |
| output.bucket | string | 是 | 输出空间名称 |

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | object | 合流信息 |
| data.mixId | string | 合流ID |
| data.status | string | 合流状态 |

## 响应示例
```json
{
  "requestId": "558f0655-f373-48e6-93fb-7c91020462e0",
  "code": 200,
  "message": "success",
  "data": {
    "mixId": "mix-123456",
    "status": "running"
  }
}
```

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 404 | 指定的流不存在 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
