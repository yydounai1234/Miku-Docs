# 直播混流

## 概述
直播混流模块提供多路直播流混合功能，支持创建合流和停止合流操作。

## 功能列表
- [创建合流](创建合流.md) - POST
- [停止合流](停止合流.md) - POST

## 混流说明
混流是将多个直播流的画面和音频混合成一路输出流的技术，常用于以下场景：
- 多人连麦直播
- 主播与观众互动
- 多画面同屏展示
- 教育直播中的讲师与课件混合

## 混流布局
支持多种混流布局方式：
- 画中画布局
- 平铺布局
- 自定义布局

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
