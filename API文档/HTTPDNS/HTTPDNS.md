# HTTPDNS

## 概述
HTTPDNS模块提供域名解析服务，帮助客户端快速获取直播服务的最优接入节点。

## 功能列表
- [dns域名解析接口](dns域名解析接口.md) - GET
- [推流/转推域名解析接口](推流转推域名解析接口.md) - GET

## HTTPDNS优势
- 避免DNS劫持
- 降低解析时延
- 实时调度最优节点
- 支持IPv6解析

## 使用场景
- 直播推流端获取最优推流节点
- 直播播放端获取最优播放节点
- 转推服务获取目标节点地址

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
