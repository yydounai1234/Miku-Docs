# 推流转推域名解析接口

## 接口名称
推流转推域名解析接口

## 接口描述
为推流或转推场景解析域名，返回最适合的接入节点地址

## 请求方法
GET

## 请求路径
```
GET /?dns&domain=<domain>&type=<type>
```

## 请求参数
| 参数名称 | 类型 | 是否必填 | 说明 |
|---------|------|---------|------|
| domain | string | 是 | 要解析的域名 |
| type | string | 是 | 解析类型，可选值：publish（推流）, relay（转推） |

## 请求示例
```http
GET /?dns&domain=live.example.com&type=publish HTTP/1.1
Host: <service-code>.<region-code>.qiniumiku.com
Authorization: <QiniuToken>
Content-Type: application/json
```

## 响应参数
| 参数名称 | 类型 | 说明 |
|---------|------|------|
| requestId | string | 请求ID |
| code | integer | 响应码 |
| message | string | 响应消息 |
| data | object | 解析结果 |
| data.domain | string | 域名 |
| data.type | string | 解析类型 |
| data.ips | array | IP地址列表 |
| data.ips[].ip | string | IP地址 |
| data.ips[].priority | integer | 优先级 |
| data.ips[].region | string | 地理区域 |
| data.ips[].isp | string | 运营商 |
| data.ttl | integer | TTL值（秒） |

## 响应示例
```json
{
  "requestId": "558f0655-f373-48e6-93fb-7c91020462e0",
  "code": 200,
  "message": "success",
  "data": {
    "domain": "live.example.com",
    "type": "publish",
    "ips": [
      {
        "ip": "192.168.1.100",
        "priority": 1,
        "region": "cn-east-1",
        "isp": "telecom"
      },
      {
        "ip": "192.168.1.101",
        "priority": 2,
        "region": "cn-east-1",
        "isp": "unicom"
      }
    ],
    "ttl": 300
  }
}
```

## 错误码
| 错误码 | 说明 |
|-------|------|
| 400 | 请求参数错误 |
| 401 | 鉴权失败 |
| 404 | 域名不存在 |
| 500 | 服务端内部错误 |

## 鉴权方式
支持 QiniuToken、IAM 鉴权和 Apikey 鉴权，请参考[请求鉴权](../公共API规范/请求鉴权.md)文档。
